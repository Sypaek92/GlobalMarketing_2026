Firebase 설정

Firebase Console → 프로젝트 설정 → 내 앱 → firebaseConfig 복사 후 붙여넣기

필수 설정 체크리스트
① Firebase Console → Authentication → 이메일/비밀번호 활성화
② Users 탭 → 사용자 직접 추가
③ Firestore Database 생성 → 보안 규칙:
  allow read, write: if request.auth != null;

모든 브라우저에서 자동 로그인되게 하려면
HTML 파일 상단 window.FIREBASE_CONFIG에 위 JSON을 붙여넣으세요.

관리자 설정 (데이터 업로드 권한)
Firestore → config 컬렉션 → admins 문서 생성 → emails 필드에 관리자 이메일 배열 추가
예: emails: ["admin@company.com"]
